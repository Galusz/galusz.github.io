Bulk File Grabber

Privacy policy

Effective 31 October 2026.

In short

Bulk File Grabber is a Chrome extension that lists the files on the page you are viewing and downloads the ones you pick. It does not collect, sell or share personal data. There is no Bulk File Grabber server, no account, no analytics and no advertising. The author never receives your browsing data, the pages you scan or the files you download.

What the extension reads

  • When you click the extension icon, it reads the links, images, video and audio sources of the current tab to show you a list of files. This happens only on the tab where you opened it, only when you open it, and the list is never sent anywhere.
  • The optional “Allow access to all sites” permission is used only by the Pro ZIP feature, which fetches the files you selected so it can pack them into one ZIP on your computer.

What is stored, and where

Everything is kept in your browser’s local extension storage on your own computer:

  • your settings (download folder, file name template, filters);
  • a list of file addresses you have already downloaded with the extension, so it can skip duplicates (up to 5,000 entries; you can clear it in Settings);
  • if you buy Pro: your licence key, the email address Gumroad returns for that key, and the date it was last checked.

What leaves your computer

  • Downloads. Files you choose are downloaded by Chrome directly from the websites that host them, as with any download.
  • Licence check (Pro only). When you activate Pro, and about once a week after that, the extension sends your licence key to Gumroad’s licence API (api.gumroad.com) to confirm the purchase is valid. Nothing else is sent. Purchases are handled by Gumroad under Gumroad’s privacy policy.

The extension does not use cookies, trackers, remote code or third-party analytics.

Removing your data

  • “Forget download history” and “Remove licence from this browser” in the extension’s Settings delete those items.
  • Removing the extension from Chrome deletes everything it stored.

Chrome Web Store user data policy

The use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
