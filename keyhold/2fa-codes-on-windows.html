Keyhold

Two-factor codes on your Windows PC

Most authenticator apps live only on the phone, so every login means reaching for it. Keyhold also runs on Windows: the six-digit code is right where you sign in, and it stays in step with your phone through your own Google Drive.

Set it up

  1. Download Keyhold for Windows, unzip it anywhere and run keyhold.exe. No installer, no account.
  2. Create a vault. Choose a master password and print the recovery sheet — its key opens the vault if you ever forget the password.
  3. Add a code. When a website shows the QR code for two-step login, choose Add two-factor codes → Scan the screen. A screenshot or a photo of the code works too (Open an image).
  4. Coming from Google Authenticator? Export your accounts there and bring them all in at once — see how to move and back up Google Authenticator codes.

Use the codes

  • Each code shows with its countdown, and in the last seconds the next code shows too.
  • Ctrl+Alt+K types a login or a code into any window.
  • The browser extension for Chrome, Edge and Firefox (it comes with the download) offers the code right under the code field — only on the site it belongs to.
  • Mark a code as protected and it is filled in only after Windows Hello.

On the phone too

Keyhold for Android shows the same codes and fills them into apps. Turn on Google Drive on both devices and they stay in step; the vault is encrypted on the device before it is sent, and Keyhold sees only the files it made itself. Drive is optional — Keyhold works offline as well.
